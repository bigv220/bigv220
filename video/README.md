# 《流星糖》视频工作台

双击 `video-workbench.html`，或用本地服务器打开后访问：

```text
http://127.0.0.1:8010/video-workbench.html
```

视频工作台已经包含：

- 露奈 Luna 的竖屏 9:16 动态歌词预览
- 《流星糖》副歌 30 秒时间线
- MP3 / WAV 本地试听与同步字幕
- 自定义 Luna 立绘替换
- 已确定的露奈 Luna 立绘已放入 `video/assets/luna-reference.png`，视频预览默认使用它
- SRT 与 WebVTT 字幕下载
- 可直接复用到 Kdenlive 的素材目录

## 使用步骤

1. 在 ACE-Step 生成并下载《流星糖》音频。
2. 打开视频工作台，选择音频文件。
3. 试听副歌预览，确认歌词节奏。
4. 选择最终 Luna 立绘替换占位图。
5. 下载 `SRT` 字幕，在 Kdenlive 中完成最终剪辑与 MP4 导出。

当前模板不上传文件，也不会自动发布视频。`video/assets/` 里的 SVG 是可替换的示例素材。
